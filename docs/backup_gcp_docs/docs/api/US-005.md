## 1. Mục tiêu

- **Vấn đề cần giải quyết:**
  Hiện tại dự án chưa có bất kỳ dịch vụ web HTTP nào. Khi triển khai lên nền tảng container (như Google Cloud Run / Docker), bộ cân bằng tải (load balancer) và hệ thống CI/CD cần một cơ chế kiểm tra sức khỏe (Health Check / Readiness Probe) trung thực. Nếu không có endpoint `/health` phản ánh đúng trạng thái nạp mô hình vào bộ nhớ, container có thể tiếp nhận lưu lượng người dùng trước khi mô hình sẵn sàng, dẫn đến lỗi hàng loạt `500 Internal Server Error` hoặc thời gian chờ vô tận (cold-start timeout).
- **Kết quả mong đợi sau US này:**
  1. Khởi tạo dịch vụ web bằng **FastAPI** tại [`src/vsl/service.py`](file:///d:/file/project/Sign-Language-Classification-v1.0/src/vsl/service.py).
  2. Quản lý vòng đời ứng dụng qua **Lifespan Context Manager**: nạp mô hình Keras đúng **1 lần duy nhất** khi container khởi động và lưu tại `app.state.model` theo quy tắc **`BR-011`**. Nghiêm cấm nạp lại mô hình trong từng request.
  3. Cài đặt endpoint công khai **`GET /health`**:
     - Trả về HTTP `200 OK` kèm thông tin model đã sẵn sàng (`model_loaded: true`) khi model nạp thành công.
     - Trả về HTTP `503 Service Unavailable` (`model_loaded: false`) nếu model chưa nạp xong hoặc gặp lỗi.
  4. Đóng vai trò là mục tiêu cho **Warm-Up ping** từ giao diện web (`BR-019`) để đánh thức container Cloud Run từ trạng thái ngủ.
- **Phạm vi:**
  - Khởi tạo FastAPI app và Lifespan handler.
  - Cài đặt endpoint `GET /health`.
  - Cập nhật dependencies phục vụ web trong `requirements.txt` (`fastapi`, `uvicorn`, `starlette`).
  - Viết bộ kiểm thử tự động `tests/test_health.py`.
- **Ngoài phạm vi:**
  - Chưa cài đặt endpoint `POST /predict` (thuộc `US-006`).
  - Chưa cài đặt endpoint `GET /version` (thuộc `US-008`).
  - Chưa cấu hình CORS middleware (thuộc `US-025`).
  - Chưa viết Dockerfile (thuộc Epic `EPC-03`).

## 6. Proposed API Changes

### 6.1. `GET /health`

- **Method:** `GET`
- **Endpoint:** `/health`
- **Purpose:** Kiểm tra trạng thái hoạt động của dịch vụ và xác nhận mô hình ResNet50 đã nạp hoàn tất vào bộ nhớ.
- **Authentication:** Public (không yêu cầu token, cho phép probe nội bộ và frontend ping).
- **Authorization:** Mọi vai trò (`A01` Người dùng cuối, `A02` Lập trình viên, `A03` CI/CD/Cloud).
- **Path Parameters:** Không.
- **Query Parameters:** Không.
- **Request Body:** Không (`None`).
- **Response Schemas:**

#### Trường hợp 1: Sẵn sàng (Model đã nạp) — HTTP 200 OK
- **HTTP Status:** `200`
- **Content-Type:** `application/json`
- **Response Body:**
  ```json
  {
    "status": "ok",
    "model_loaded": true,
    "model_version": "v1.0"
  }
  ```

#### Trường hợp 2: Chưa sẵn sàng (Đang nạp hoặc Lỗi nạp) — HTTP 503 Service Unavailable
- **HTTP Status:** `503`
- **Content-Type:** `application/json`
- **Response Body:**
  ```json
  {
    "status": "degraded",
    "model_loaded": false,
    "model_version": null
  }
  ```

- **Validation:**
  - Kiểm tra `hasattr(app.state, "model") and app.state.model is not None`.
  - Tuyệt đối không gọi lệnh nạp model bên trong handler của endpoint.
- **Business Rules:**
  - `BR-011`: Mô hình nạp 1 lần duy nhất trong lifespan context; endpoint chỉ trả 200 sau khi nạp xong.
  - `BR-019`: Dùng làm điểm nhận warm-up ping từ trang web để khởi động container.

## 7. Business Flow

```
1. Khởi động Container (FastAPI Lifespan Startup):
   ┌───────────────────────────────────────────────┐
   │ lifespan() context manager                    │
   │  ├── Đọc model_path = get_model_path()        │
   │  ├── Keras load_model(str(model_path))        │
   │  └── Gán app.state.model = model              │
   │  └── Gán app.state.model_version = "v1.0"     │
   └───────────────────────────────────────────────┘
                          │
                          ▼
2. Client / Cloud Run gửi request GET /health:
                          │
                          ▼
            Kiểm tra app.state.model?
                   /             \
                 CÓ              KHÔNG / LỖI
                /                 \
               ▼                   ▼
        HTTP 200 OK         HTTP 503 Service Unavailable
        {                   {
          status: "ok",       status: "degraded",
          model_loaded: true, model_loaded: false,
          model_version: "v1.0" model_version: null
        }                   }
```
