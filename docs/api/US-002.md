## 1. Mục tiêu

- **Vấn đề cần giải quyết:** Danh sách `VIETNAMESE_ALPHABET` đang bị định nghĩa lặp lại ở **4 nơi** (`train/train_cnn_pose_keras.ipynb`, `run_realtime.ipynb`, `run_realtime.py`, `process_images/capture_and_process_images.ipynb`). Đồng thời, lệnh one-hot encoding trong notebook huấn luyện đang hard-code số cứng `np.eye(23)[labels]`. Nếu thêm/bớt ký tự hoặc đổi thứ tự mà quên sửa đồng bộ, model sẽ gán sai nhãn âm thầm (silent failure) hoặc gãy shape khi huấn luyện lại.
- **Kết quả mong đợi sau US này:**
  1. Chỉ còn **duy nhất một định nghĩa** `VIETNAMESE_ALPHABET` trong module `src/vsl/labels.py`, tự động suy ra `NUM_CLASSES = len(VIETNAMESE_ALPHABET)`.
  2. Toàn bộ notebook và script (`run_realtime.py`) đều import từ `src.vsl.labels` (hoặc `src.vsl`).
  3. Lệnh `np.eye(23)` trong notebook huấn luyện được thay bằng `np.eye(NUM_CLASSES)`.
- **Phạm vi:** Trích xuất module `src/vsl/labels.py`, re-export qua `src/vsl/__init__.py`, dọn dẹp các bản sao cục bộ, thay `np.eye(23)` bằng `np.eye(NUM_CLASSES)`, cập nhật test suite.
- **Ngoài phạm vi:** Không sửa logic đường dẫn tuyệt đối `D:\...` (thuộc US-003), không sửa requirements/headless (thuộc US-004), không train lại model hay sửa cấu trúc ResNet50.

## 6. Proposed API Changes

### 6.1. Hợp đồng Module `src/vsl/labels.py`

- **Loại:** Module hằng số và tiện ích Python thuần (in-process)
- **Đường dẫn module:** `src/vsl/labels.py` (và re-export tại `src/vsl/__init__.py`)
- **Authentication / Authorization:** N/A (thư viện nội bộ)

#### Các hằng số xuất bản (Public Exports):

1. **`VIETNAMESE_ALPHABET`**:
   - **Kiểu:** `tuple[str, ...]` (chọn `tuple` để đảm bảo tính bất biến - immutability, ngăn ngừa vô tình sửa đổi runtime; vẫn tương thích 100% với indexing `[i]`, duyệt loop `for letter in ...`, và `.index(letter)`).
   - **Số lượng phần tử:** Đúng **23 phần tử**.
   - **Thứ tự bắt buộc (BR-003):**
     ```python
     VIETNAMESE_ALPHABET = (
         "a", "b", "c", "d", "đ", "e", "g", "h", "i", "k", "l", "m", "n",
         "o", "p", "q", "r", "s", "t", "u", "v", "x", "y"
     )
     ```
   - **Ràng buộc ký tự:** Bắt buộc có ký tự `'đ'`; tuyệt đối **không** có các ký tự `'f'`, `'j'`, `'w'`, `'z'`.
   - **Ý nghĩa chỉ số:** Index trong `VIETNAMESE_ALPHABET` chính là index lớp xác suất softmax từ mô hình ResNet50 (`predicted_letter = VIETNAMESE_ALPHABET[class_idx]`).

2. **`NUM_CLASSES`**:
   - **Kiểu:** `int`
   - **Công thức:** `NUM_CLASSES = len(VIETNAMESE_ALPHABET)`
   - **Giá trị hiện tại:** `23`
   - **Mục đích:** Thay thế mọi magic number `23` liên quan đến số lượng lớp trong one-hot encoding và kiến trúc mạng.

## 7. Business Flow

```
[Khởi tạo Module / Pipeline]
       │
       ▼
src/vsl/labels.py
  ├── VIETNAMESE_ALPHABET: tuple (23 ký tự chuẩn)
  └── NUM_CLASSES = len(VIETNAMESE_ALPHABET)
       │
       ├──► [Dữ liệu]: capture_and_process_images.ipynb
       │      duyệt thư mục theo VIETNAMESE_ALPHABET
       │
       ├──► [Huấn luyện]: train_cnn_pose_keras.ipynb
       │      map nhãn -> idx -> one-hot: np.eye(NUM_CLASSES)[labels]
       │      model output: Dense(NUM_CLASSES, activation='softmax')
       │
       ├──► [Suy luận native]: run_realtime.py
       │      class_idx = np.argmax(prediction)
       │      predicted_letter = VIETNAMESE_ALPHABET[class_idx]
       │
       └──► [Suy luận notebook]: run_realtime.ipynb
              predicted_letter = VIETNAMESE_ALPHABET[class_idx]
```

## 15. Risks & Mitigation

| Rủi ro | Mức độ | Ảnh hưởng | Biện pháp giảm thiểu |
|---|---|---|---|
| Kiểu `tuple` gây lỗi không mong muốn ở code cũ mong đợi `list` | Thấp | Code gọi phương thức chỉ có ở list như `.append()` | Đã kiểm tra: code cũ chỉ dùng indexing `ALPHABET[idx]` và `enumerate(ALPHABET)`. `tuple` đáp ứng hoàn hảo và giúp bất biến |
| Sửa file `.ipynb` (JSON) gây hỏng cấu trúc notebook | Trung bình | Notebook không mở được trong Jupyter | Dùng script parse JSON chuẩn hoặc kiểm tra cú pháp JSON hợp lệ sau khi sửa |
| Sót định nghĩa `VIETNAMESE_ALPHABET` ở file script/test | Thấp | Vi phạm Single Source of Truth | Test scenario T6 quét tự động toàn bộ codebase |
