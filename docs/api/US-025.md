---

## 1. Mục tiêu
- Vấn đề: Frontend và backend nằm khác origin, nếu không cấu hình CORS chính xác thì trình duyệt sẽ chặn request.
- Kết quả: Backend chỉ cho phép origin Cloudflare Pages (`*.pages.dev`) và localhost; xử lý preflight `OPTIONS`; cấm ký tự đại diện `*` (BR-018). Phân loại rõ 3 trạng thái lỗi: Cold start (503), Lỗi mạng, Lỗi nghiệp vụ (400).
- Phạm vi: `src/vsl/service.py`, `tests/test_ops_contract.py`.

## 6. Proposed API Changes (CORS Headers)
- **Allowed Origins:** `https://vsl-frontend.pages.dev`, `http://localhost:3000`, `http://localhost:5173`, `http://localhost:8080`.
- **Allowed Origin Regex:** `^https:\/\/([a-zA-Z0-9-]+\.)?vsl-frontend\.pages\.dev$` (hỗ trợ preview branches trên Cloudflare Pages).
- **Allowed Methods:** `GET`, `POST`, `OPTIONS`.
- **Allowed Headers:** `*`.
- **Allow Credentials:** `True`.

---

## 7. Business Flow & Error States
```
Trình duyệt gửi OPTIONS (preflight)
  → Backend kiểm tra Origin
  → Nếu hợp lệ: trả 200 OK kèm Access-Control-Allow-Origin
  → Nếu không hợp lệ: không cấp header CORS

Trình duyệt gửi POST /predict
  → Trường hợp 1: Model đang tải lúc khởi động nguội → trả 503 Service Unavailable
  → Trường hợp 2: Ảnh hỏng không giải mã được → trả 400 Bad Request
  → Trường hợp 3: Thành công → trả 200 OK kèm kết quả dự đoán
```
