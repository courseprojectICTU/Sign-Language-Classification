feature/US-038

- Phạm vi: `src/vsl/service.py`, `tests/test_ops_contract.py`.

## 7. Business Flow & Error States
```
Trình duyệt gửi OPTIONS (preflight)
  → Backend kiểm tra Origin
  → Nếu hợp lệ: trả 200 OK kèm Access-Control-Allow-Origin
  → Nếu không hợp lệ: không cấp header CORS

Trình duyệt gửi POST /predict
  → Trường hợp 1: Model đang tải lúc khởi động nguội → trả 503 Service Unavailable
  → Trường hợp 2: Ảnh hỏng không giải mã được → trả 400 Bad Request
  → Trường hợp 3: Thành công → trả 200 OK kèm kết quả dự đoán
```

## 6. Proposed API Changes

### 6.1. CORS response policy

- **Method / Endpoint:** Không thêm hoặc đổi endpoint; áp dụng middleware cho các route hiện có.
- **Authentication / Authorization:** Không thay đổi.
- **Allowed origins:** Giá trị phân tách bằng dấu phẩy từ `VSL_ALLOWED_ORIGINS`; mỗi giá trị
  phải là một origin HTTP(S) đầy đủ, ví dụ `https://<project>.pages.dev`.
- **Default:** Danh sách rỗng; không cho phép cross-origin nếu operator chưa cấu hình.
- **Wildcard:** `*` bị từ chối; không dùng origin regex hoặc suffix wildcard.
- **Methods:** `GET`, `POST`, `OPTIONS`.
- **Headers:** `Content-Type`; credentials không được bật.
- **Preflight:** Origin hợp lệ và method được phép nhận response CORS từ middleware.
- **Invalid configuration:** Origin có wildcard, path, query, fragment hoặc không phải
  HTTP(S) làm khởi tạo app lỗi rõ ràng thay vì tự mở rộng allowlist.
- **HTTP status / body:** Endpoint và response body hiện có không thay đổi; request CORS
  bị từ chối không có `Access-Control-Allow-Origin`.

### 6.2. Environment variable

```text
VSL_ALLOWED_ORIGINS=https://<actual-cloudflare-pages-host>
```

Có thể cấu hình nhiều origin bằng dấu phẩy. Chỉ đưa hostname đã xác minh vào deployment
environment; giá trị mặc định rỗng không cấp quyền cho bất kỳ site khác origin nào.

## 7. Business Flow

```text
FastAPI khởi tạo
  -> parse VSL_ALLOWED_ORIGINS thành origin HTTP(S) chính xác
  -> reject cấu hình wildcard hoặc URI không phải origin
  -> CORSMiddleware xử lý request/preflight
  -> origin trong allowlist nhận CORS headers; origin khác không nhận
```

## 15. Risks

| Rủi ro | Ảnh hưởng | Giảm thiểu |
|---|---|---|
| Chưa biết hostname Pages thực tế | Browser calls sẽ bị chặn tới khi cấu hình đúng | Operator lấy domain từ Cloudflare Pages và set `VSL_ALLOWED_ORIGINS` |
| Origin sai hoặc có dấu `/path` | Backend từ chối cấu hình hoặc browser không khớp | Ghi chính xác scheme + host (+ port nếu có), không path |
| CORS bị nhầm là xác thực | API public vẫn có thể được gọi ngoài browser | Không coi CORS là cơ chế bảo vệ API |
