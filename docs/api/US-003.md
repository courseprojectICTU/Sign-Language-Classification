- **Kết quả mong đợi sau US này:**
  1.   3. Loại bỏ 100% chuỗi đường dẫn tuyệt đối `D:\...` trong toàn bộ mã nguồn của repository.
  4. Các notebook, script (`run_realtime.py`), và launcher `.cmd` chuyển sang dùng module `src.vsl.config` hoặc cơ chế tìm đường dẫn linh hoạt.

## 6. Proposed API Changes

### 6.1. Module `src/vsl/config.py`

- **Purpose:** Điểm tập trung cấu hình đường dẫn cho toàn bộ dự án, hỗ trợ cấu hình động qua biến môi trường và fallback đường dẫn tương đối.
- **Biến môi trường hỗ trợ:**
  - `VSL_MODEL_PATH`: Đường dẫn tuyệt đối hoặc tương đối tới file trọng số mô hình `.h5`.
  - `VSL_DATA_DIR`: Đường dẫn tuyệt đối hoặc tương đối tới thư mục dữ liệu landmark (mặc định chứa các thư mục con chữ cái).
- **Hằng số và Hàm công khai:**

```python
from pathlib import Path
import os

# Thư mục gốc của repository (xác định tự động dựa trên vị trí của file config.py)
PROJECT_ROOT: Path = Path(__file__).resolve().parent.parent.parent

def get_model_path() -> Path:
    """
    Trả về đường dẫn tới file mô hình Keras (.h5).
    Ưu tiên biến môi trường VSL_MODEL_PATH.
    Nếu không có, fallback về <PROJECT_ROOT>/train/vsl_cnn_pose_keras.h5.
    """
    env_val = os.environ.get("VSL_MODEL_PATH")
    if env_val:
        return Path(env_val)
    return PROJECT_ROOT / "train" / "vsl_cnn_pose_keras.h5"

def get_data_dir() -> Path:
    """
    Trả về đường dẫn tới thư mục dữ liệu landmark CSV.
    Ưu tiên biến môi trường VSL_DATA_DIR.
    Nếu không có, fallback về <PROJECT_ROOT>/data/anphabet.
    """
    env_val = os.environ.get("VSL_DATA_DIR")
    if env_val:
        return Path(env_val)
    return PROJECT_ROOT / "data" / "anphabet"

# Hằng số tiện ích tại thời điểm import
MODEL_PATH: Path = get_model_path()
DATA_DIR: Path = get_data_dir()
BASE_PATH: Path = DATA_DIR  # Alias tương thích ngược cho notebook cũ
```

### 6.2. Re-export trong `src/vsl/__init__.py`

```python
from src.vsl.config import (
    BASE_PATH,
    DATA_DIR,
    MODEL_PATH,
    PROJECT_ROOT,
    get_data_dir,

)
```

## 8. Security

| Mục | Giá trị |
|---|---|
| Authentication / Authorization | Không áp dụng (Module thư viện Python nội bộ) |
| Xử lý biến môi trường | Đọc an toàn qua `os.environ.get()`, không gây crash nếu biến không tồn tại |
| Path Traversal | Chấp nhận đường dẫn từ env do lập trình viên/hệ thống CI cấu hình. Không nhận input trực tiếp từ người dùng cuối chưa xác thực |
| Sensitive Data | Không có khóa bí mật hay dữ liệu nhạy cảm trong file cấu hình |

## 15. Risks

| Rủi ro | Ảnh hưởng | Giảm thiểu |
|---|---|---|
| Notebook chứa output cũ có chuỗi `D:\` | `AC-003-01` bị fail khi quét text trong `.ipynb` | Dọn dẹp/clear output chứa đường dẫn tuyệt đối cũ trong notebook |
