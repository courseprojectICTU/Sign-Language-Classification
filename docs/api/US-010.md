## 1. Mục tiêu

- **Vấn đề cần giải quyết:** Hiện tại mã nguồn backend chỉ chạy trực tiếp trong môi trường Python host Windows (`python -m uvicorn`), chưa có artifact container chuẩn hóa để triển khai bất biến lên môi trường Linux và Google Cloud Run.
- **Kết quả mong đợi:**
  - Có file `.dockerignore` loại bỏ context rác (`.git`, `.venv`, `data/`, `notebooks`, cache).
  - Có file `Dockerfile` chuẩn Linux (`linux/amd64`, `python:3.12-slim`), cài đặt đủ thư viện runtime (`libgl1`, `libglib2.0-0`), sao chép model và mã nguồn `src/`.
  - Cấu hình chỉ thị `HEALTHCHECK` thăm dò `/health` và chạy Uvicorn tại cổng `8080`.
  - Thực hiện thành công `docker build` và `docker run`, phản hồi HTTP 200 tại `/health` trong vòng 60 giây.
- **Phạm vi:** Tạo `Dockerfile`, `.dockerignore`, kiểm thử tự động cấu trúc dockerfile và kiểm chứng lệnh `docker build` / `docker run` cục bộ.
- **Ngoài phạm vi:** Đẩy image lên Artifact Registry (US-029), cấu hình workflow CI build image (US-026), chuyển đổi model sang ONNX (US-011), triển khai Terraform Cloud Run (US-021).

## 3. Existing Architecture

- **Backend:** FastAPI service đã hoàn thiện tại `src/vsl/service.py` với 3 endpoints: `GET /health`, `POST /predict`, `GET /version`.
- **Cấu hình & Model:** `src/vsl/config.py` đọc đường dẫn tương đối từ `PROJECT_ROOT` hoặc qua biến môi trường `VSL_MODEL_PATH`. File model `train/vsl_cnn_pose_keras.h5` (137 MB) đã được smudge đầy đủ qua Git LFS.
- **Phụ thuộc:** `requirements.txt` đã được ghim sạch chuẩn ASCII, dùng `opencv-python-headless` (US-004).
- **Hiện trạng Container:** Chưa có `Dockerfile`, chưa có `.dockerignore`.

## 6. Proposed Container & Build Specifications

### 6.1. Đặc tả `.dockerignore`

Loại trừ triệt để các tệp không cần thiết cho môi trường runtime để tối ưu build context và tốc độ truyền:
```dockerignore
# VCS & CI
.git
.github
.gitignore
.gitattributes

# Virtual environments & Dependencies
.venv/
venv/
env/

# Data & Notebooks (Dữ liệu thô và tài liệu nghiên cứu)
data/
process_images/
run_notebook.cmd
run_realtime.cmd
run_realtime.py
run_realtime.ipynb
*.ipynb

# Python cache & Testing artifacts
__pycache__/
*.py[cod]
*$py.class
.pytest_cache/
tests/
requirements-dev.txt

# Documentation & Reports
docs/
report/
*.md
*.doc
*.docx
*.txt

# Training visual plots
train/training_plot_keras.png
```

### 6.2. Đặc tả `Dockerfile`

Tuân thủ nghiêm ngặt các quy tắc:
1. **Base Image:** `python:3.12-slim` (chỉ định nền tảng `--platform=linux/amd64` theo BR-025).
2. **System Dependencies:** Cài đặt `libgl1`, `libglib2.0-0` (bắt buộc cho MediaPipe & OpenCV headless) và `curl` (dùng cho healthcheck). Dọn dẹp cache apt trong cùng một layer (`rm -rf /var/lib/apt/lists/*`).
3. **Python Dependencies:** Sao chép `requirements.txt` trước và chạy `pip install --no-cache-dir -r requirements.txt` để tận dụng cache layer khi mã nguồn thay đổi.
4. **Build Arguments & Env:**
   - `ARG GIT_SHA=unknown` $\to$ `ENV GIT_SHA=${GIT_SHA}` (BR-009)
   - `ARG BUILD_TIME=""` $\to$ `ENV BUILD_TIME=${BUILD_TIME}`
   - `ENV PYTHONUNBUFFERED=1`
   - `ENV PORT=8080`
5. **App Artifacts:**
   - Thư mục làm việc: `WORKDIR /app`
   - Sao chép gói mã nguồn: `COPY src/ /app/src/`
   - Sao chép mô hình: `COPY train/vsl_cnn_pose_keras.h5 /app/train/vsl_cnn_pose_keras.h5`
6. **Healthcheck:**
   - `HEALTHCHECK --interval=30s --timeout=5s --start-period=30s --retries=3 CMD curl -f http://localhost:8080/health || exit 1`
7. **Port & Run Command:**
   - `EXPOSE 8080`
   - `CMD ["uvicorn", "src.vsl.service:app", "--host", "0.0.0.0", "--port", "8080"]`

## 7. Business Flow & Lifecycle

```text
Docker Build:
  1. docker build --build-arg GIT_SHA=$(git rev-parse HEAD) -t vsl-api .
  2. Docker đọc .dockerignore (Context giảm từ ~3 GB xuống ~150 MB)
  3. Cài libgl1, libglib2.0-0, curl
  4. Cài đặt requirements.txt
  5. Copy src/ và model .h5 vào /app
  6. Xuất xưởng image linux/amd64 bất biến

Docker Run:
  1. docker run -d -p 8080:8080 --name vsl-service vsl-api
  2. Uvicorn khởi động -> FastAPI Lifespan kích hoạt
  3. Model nạp vào app.state (mất ~10-20s theo BR-011)
  4. Docker HEALTHCHECK gọi curl http://localhost:8080/health
  5. Sau khi model nạp xong: /health trả HTTP 200 {"status": "ok", "model_loaded": true}
  6. Container chuyển sang trạng thái "healthy"
```

## 8. Security

| Mục | Giá trị thực thi trong Docker |
|---|---|
| **User Privileges** | Sử dụng thư viện chuẩn; không mount Docker socket vào container |
| **Secrets & Credentials** | Tuyệt đối **không** copy file `.env`, API key, SSH key hoặc token vào image |
| **Port exposure** | Chỉ mở cổng duy nhất `8080` phục vụ HTTP API |
| **Context Isolation** | `.dockerignore` ngăn ngừa rò rỉ mã nguồn test, tài liệu nội bộ và dữ liệu nhạy cảm |

## 15. Risks & Mitigation

| Rủi ro | Mức độ | Biện pháp giảm thiểu |
|---|:---:|---|
| **Lỗi thiếu thư viện hệ thống C++ của OpenCV/MediaPipe** | Cao | Cài đặt rõ ràng `libgl1` và `libglib2.0-0` trong `apt-get install` |

| **Mô hình bị nạp lại từng request gây chậm** | Trung bình | Tái sử dụng FastAPI lifespan (BR-011) đã được kiểm chứng ở US-005 |
