## 1. Mục tiêu

- Vấn đề cần giải quyết: hướng dẫn CI/CD hiện dùng `AZURE_CREDENTIALS` chứa
  `clientSecret` và ACR username/password; pipeline không có cơ chế tin cậy OIDC.
- Kết quả mong đợi: GitHub Actions xác thực Azure bằng federated identity,
  không dùng client secret hoặc service-account key JSON; quyền push và deploy
  được giới hạn theo tài nguyên.
- Phạm vi: adopt ACR `vslacr3795` hiện có vào Terraform; tạo Azure application,
  Service Principal và Federated Identity Credential cho GitHub; cấp quyền
  triển khai tối thiểu; tạo ACR Task dọn image để giữ tối đa 3 tag mới nhất mỗi
  repository sau mỗi lần chạy; cập nhật hướng dẫn CI/CD liên quan.
- Ngoài phạm vi: chạy Terraform apply/import lên Azure trong giai đoạn phân tích,
  triển khai revision Container Apps, đổi cấu hình pull image runtime của ứng
  dụng, cấu hình production, hoặc tạo pipeline CD hoàn chỉnh.

## 3. Existing Architecture

- Backend: FastAPI trên Azure Container Apps; staging Resource Group là
  `rg-vsl-staging`, Container App là `vsl-api`.
- Frontend: chưa có trong repository; không bị thay đổi bởi US-019.
- Terraform: root module dùng AzureRM provider `~> 4.0`, Terraform `>= 1.5.0`
  và Azure Blob remote state; hiện chưa khai báo registry hay deployment IAM.
- ACR: tài liệu bàn giao ghi nhận `vslacr3795.azurecr.io` (Basic); registry
  hiện có sẽ được adopt vào Terraform, không tạo registry trùng.
- Workflow: chưa có GitHub Actions workflow ngoài các mẫu/quy ước repository;
  cần thêm workflow smoke test có `workflow_dispatch`.
- Quy ước lỗi: Terraform CLI trả diagnostic/exit code; GitHub Actions đánh dấu
  job thất bại nếu Azure OIDC login không thành công. Không được thay lỗi bằng
  kết quả giả thành công.

## 6. Proposed API Changes

### 6.1 Terraform CLI contract

- **Method:** N/A — Terraform CLI.
- **Endpoint:** N/A.
- **Purpose:** Khai báo ACR hiện có, cleanup task, deployment principal,
  federated credential và role assignments; xem thay đổi bằng `terraform plan`.
- **Authentication:** Azure CLI/Azure AD của người vận hành Terraform. GitHub
  Actions dùng token OIDC ngắn hạn qua `azure/login@v2`; không dùng client
  secret hoặc service-account key JSON.
- **Authorization:** Identity chạy Terraform cần quyền quản lý Azure resources
  và Entra application/service principal/federated credentials; các quyền này
  do admin cấp ngoài US-019. Không tự tạo role assignment cho identity chạy
  Terraform.
- **Path Parameters:** Không áp dụng.
- **Query Parameters:** Không áp dụng.
- **Request Body:** Không áp dụng. Đầu vào là variables/tfvars theo môi trường,
  subscription, Resource Group, registry và Container App đích.
- **Response:** Terraform plan/diagnostics và exit code; exit code `0` biểu thị
  plan hợp lệ, không đồng nghĩa đã áp dụng lên Azure.
- **HTTP Status:** Không áp dụng.
- **Validation:** ACR import phải trỏ đúng
  `vslacr3795` trong `rg-vsl-staging`; plan không được thay thế/xóa registry.
  Federated credential phải khớp issuer, audience và subject đã duyệt. Role
  assignments phải giới hạn ở ACR/Container App đích.
- **Business Rules:** `BR-015`; không tạo/lưu service-account key JSON hoặc
  client secret. Deployment principal chỉ nhận `AcrPush` trên ACR và
  `Container Apps Contributor` trên Container App `vsl-api`. Identity riêng
  cho cleanup chỉ nhận `AcrDelete` trên ACR.
- **Error Cases:** Sai subscription/resource ID, xung đột khi adopt ACR, thiếu
  quyền Entra/Azure, FIC subject không khớp hoặc plan yêu cầu replace/delete
  registry phải dừng và báo lỗi; không chạy apply tự động.

### 6.2 GitHub Actions Azure OIDC smoke workflow

- **Method:** `workflow_dispatch`.
- **Endpoint:** N/A — thao tác GitHub Actions.
- **Purpose:** Xác minh repository có thể lấy GitHub OIDC token và đăng nhập
  Azure bằng Federated Identity Credential.
- **Authentication:** `azure/login@v2` với OIDC; job khai báo
  `permissions: id-token: write` và `contents: read`.
- **Authorization:** Chỉ workflow token có subject
  `repo:courseprojectICTU@343123217/Sign-Language-Classification@1421059989:ref:refs/heads/develop`
  được FIC chấp nhận.
- **Path Parameters:** Không áp dụng.
- **Query Parameters:** Không áp dụng.
- **Request Body:** Không áp dụng. Client ID, tenant ID và subscription ID là
  identifier; workflow đọc từ GitHub Actions Variables, không phải secret.
  Terraform xuất ba identifier này dưới dạng outputs để cấu hình Variables.
- **Response:** Job thành công sau `azure/login` và lệnh kiểm tra subscription
  tối thiểu; không in access token hoặc thông tin credential.
- **HTTP Status:** Không áp dụng.
- **Validation:** Workflow chỉ được phép chạy từ `develop`; subject/audience
  không đúng phải khiến login thất bại. Audience công cộng là
  `api://AzureADTokenExchange`.
- **Business Rules:** `BR-015`; không tham chiếu `AZURE_CREDENTIALS`,
  `clientSecret`, ACR username/password hoặc service-account key.
- **Error Cases:** Thiếu `id-token: write`, GitHub variable sai, FIC subject
  không khớp hoặc Azure role chưa được cấp phải làm workflow thất bại rõ ràng.

## 7. Business Flow

```text
Adopt ACR vslacr3795 bằng Terraform import (không tạo registry trùng)
  → tạo Azure application + Service Principal
  → tạo Federated Identity Credential cho issuer GitHub,
    audience api://AzureADTokenExchange và subject develop đã duyệt
  → cấp AcrPush trên ACR và Container Apps Contributor trên vsl-api
  → cấp AcrDelete riêng cho managed identity của cleanup task
  → ACR Task chạy hằng ngày acr purge
    --filter 'vsl-api:.*' --ago 0d --keep 3
  → GitHub Actions workflow_dispatch lấy OIDC token
  → azure/login xác thực Azure không dùng secret dài hạn
```

Cleanup dựa trên `acr purge` (preview). Cấu hình đề xuất chạy hằng ngày với
`--filter 'vsl-api:.*' --ago 0d --keep 3`, giữ 3 tag mới nhất đủ điều kiện mỗi
repository sau lần purge. Tag mới hơn age filter hoặc image được đẩy trong lúc
task chạy có thể khiến số image vượt 3 cho tới lần chạy tiếp theo. Đây không
phải giới hạn tức thời.

## 8. Security

| Mục | Giá trị |
|---|---|
| Authentication | GitHub OIDC token ngắn hạn; Azure CLI/Azure AD cho Terraform |
| Authorization | `AcrPush` ở scope ACR; `Container Apps Contributor` ở scope `vsl-api`; `AcrDelete` cho managed identity cleanup ở scope ACR |
| Role được phép | Deployment Service Principal và managed identity chuyên dụng cho ACR cleanup; không cấp `Owner`/`Contributor` ở subscription hoặc Resource Group |
| Dữ liệu nhạy cảm | Không tạo client secret; không lưu/in OIDC token hoặc Azure access token |
| Giới hạn tần suất | ACR cleanup chạy hằng ngày; GitHub workflow chỉ xác thực thủ công qua `workflow_dispatch` |
| Không được đưa vào workflow/repository | Service-account key JSON, `clientSecret`, `AZURE_CREDENTIALS`, ACR username/password hoặc access token |

US-019 không đổi cấu hình ACR admin user hoặc credential pull hiện có của
Container App; thay đổi runtime pull authentication cần phối hợp với US-020
để tránh làm gián đoạn staging.

## 10. Audit Impact

- Có cần ghi log/audit không: Có, dùng Azure Activity Log, ACR Task logs và
  GitHub Actions run logs sẵn có.
- Ghi gì: danh tính thao tác, trạng thái Terraform plan, kết quả Azure login và
  kết quả cleanup; không ghi token hoặc credential.
- Lưu ở đâu: Azure Activity Log, ACR Task execution logs và GitHub Actions.

## 11. Data Model Impact

- Entity/bảng bị ảnh hưởng: Không có database ứng dụng; Azure ACR, Entra
  application/service principal, Federated Identity Credential, Azure role
  assignments và ACR Task.
- Trường thêm/sửa: Terraform variables/tfvars cho registry, GitHub subject,
  deployment target và schedule.
- Migration cần không: Không có migration ứng dụng. ACR hiện có cần được import
  vào Terraform state staging; không được thay thế hoặc xóa registry.

## 15. Risks

| Rủi ro | Ảnh hưởng | Giảm thiểu |
|---|---|---|
| ACR đã tồn tại ngoài Terraform | Tạo trùng hoặc plan xóa/thay thế registry có thể làm gián đoạn dịch vụ | Import đúng ID; review plan; dừng nếu có replace/destroy; chưa chạy apply |
| ACR Task `acr purge` đang ở preview | API/behavior có thể thay đổi; cleanup xóa image không thể khôi phục | Giới hạn filter tới `vsl-api`, dùng `--keep 3`, xác minh dry-run trước khi bật schedule |
| Purge chạy theo lịch | Có thể tạm thời có hơn 3 image giữa các lần chạy | Nêu rõ giới hạn là sau mỗi lần purge, không phải quota tức thời |
| Thiếu Entra directory permissions | Terraform không tạo được application/SP/FIC | Admin cấp quyền cần thiết ngoài repo; không cấp quyền rộng cho GitHub deployment identity |
| Đổi registry admin/runtime credential | Có thể làm ACA không pull được image | US-019 không đổi cấu hình runtime pull; xử lý riêng cùng US-020 |
| Production chưa có giá trị xác thực | Không thể plan/apply production an toàn | Chỉ cấu hình và kiểm thử staging; không thay placeholder production |
