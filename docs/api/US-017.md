## 1. Mục tiêu
- Vấn đề: Cần kiểm tra sức khỏe và tính sẵn sàng của container sau triển khai trước khi chuyển traffic cho người dùng.
- Kết quả: Endpoint `GET /version` và script `scripts/smoke_test.py` gọi tuần tự `/health` $\to$ `/version` $\to$ `/predict`. Trả mã thoát khác 0 nếu thất bại để kích hoạt rollback tự động (BR-013).

---

## 4. Proposed Endpoint: `GET /version`
- **Method:** `GET`
- **Path:** `/version`
- **Query Params:** None
- **Response Format:**
```json
{
  "version": "1.0.0",
  "git_sha": "06095d7",
  "model_version": "v1.0"
}
```
- **HTTP Status:** `200 OK`

---

## 5. Smoke Test Execution Flow
```
CI/CD deploy revision mới với 0% traffic
  → Chạy: python scripts/smoke_test.py --url $REVISION_URL --expected-sha $GIT_SHA
  → Bước 1: GET /health (Kỳ vọng 200, status="ok", model_loaded=true)
  → Bước 2: GET /version (Kỳ vọng 200, git_sha khớp)
  → Bước 3: POST /predict (Gửi ảnh multipart thử nghiệm)
  → Nếu tất cả PASS (exit code 0): chuyển 100% traffic sang revision mới
  → Nếu FAIL (exit code 1): giữ nguyên traffic cũ và báo động
```
