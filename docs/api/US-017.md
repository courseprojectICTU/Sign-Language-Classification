# CLI Design — US-017 Smoke test tự động sau triển khai

> **Trạng thái:** `ANALYSIS_READY` — thiết kế CLI độc lập; chưa có pipeline triển khai để tích hợp
> **Epic:** `EPC-04` · **Nhánh:** `feature/US-017` · **Ngày:** 2026-11-07
> **Business Rule:** BR-013 (Deploy-Then-Shift Traffic)
>
> Hợp đồng này chỉ quy định smoke-test CLI. Nó không tuyên bố đã kiểm tra production,
> không thay đổi traffic và không thay thế bước triển khai thuộc US-029.

---

## 1. Mục tiêu

- Kiểm tra `/health`, `/version` và `/predict` trên một URL do người vận hành truyền vào.
- Chỉ trả mã thoát `0` khi model sẵn sàng, Git SHA khớp và response dự đoán hợp lệ.
- Phạm vi: CLI Python dùng được trên local và có thể được gọi từ CI/CD; ngoài phạm vi là
  triển khai, chuyển traffic, rollback hoặc kiểm tra revision production tự động.
- Người gọi phải cung cấp URL, SHA cần triển khai và ảnh kiểm thử; không hard-code môi
  trường, secret hay fixture ảnh chưa được xác minh.

## 6. Proposed API Changes

### 6.1. CLI `scripts/smoke_test.py`

- **Method / Endpoint:** CLI, không tạo endpoint mới.
- **Purpose:** Kiểm tra ba endpoint hiện có của một URL triển khai.
- **Authentication / Authorization:** Không thêm cơ chế xác thực. URL hiện tại public;
  nếu môi trường tương lai yêu cầu auth, cần mở rộng có chủ đích, không nhận secret qua log.
- **Arguments:** `--url` (bắt buộc), `--expected-sha` (bắt buộc), `--image` (bắt buộc),
  `--timeout` (giây, mặc định hữu hạn).
- **Request body:** Không có cho GET. `/predict` nhận multipart/form-data, field `file`,
  chứa bytes của file ảnh do người gọi chọn.
- **Thành công:** HTTP 200; `/health` có `model_loaded=true`; `/version.git_sha`
  khớp chính xác SHA kỳ vọng; `/predict` có `status="ok"`, `detected=true`,
  `letter` không rỗng và `confidence` hữu hạn trong [0, 1].
- **Exit status:** `0` khi cả ba bước hợp lệ; khác `0` nếu lỗi HTTP/network/JSON,
  readiness sai, SHA lệch, file ảnh không hợp lệ hoặc response dự đoán không hợp lệ.
- **Error behavior:** Ghi bước lỗi ra stderr, không in nội dung ảnh hay thành công giả.
- **Business Rules:** BR-013 — CLI cung cấp tín hiệu để deploy workflow quyết định có
  chuyển traffic hay không; bản thân CLI không chuyển traffic.

Ví dụ:

```powershell
python scripts/smoke_test.py `
  --url https://<revision-url> `
  --expected-sha <commit-sha> `
  --image <path-to-valid-test-image>
```

### 6.2. Các endpoint được gọi

| Thứ tự | Request | Điều kiện chấp nhận |
|---|---|---|
| 1 | `GET {url}/health` | Status 200 và JSON `model_loaded` đúng boolean `true` |
| 2 | `GET {url}/version` | Status 200 và `git_sha` trùng `--expected-sha` |
| 3 | `POST {url}/predict` | Status 200 và response dự đoán thỏa schema tối thiểu ở trên |

## 7. Business Flow

```text
Validate CLI arguments và file ảnh local
  -> GET /health; dừng khác 0 nếu HTTP hoặc model readiness sai
  -> GET /version; dừng khác 0 nếu git_sha không trùng SHA kỳ vọng
  -> POST /predict multipart file; dừng khác 0 nếu HTTP/JSON/dự đoán sai
  -> trả 0 chỉ khi cả ba bước thành công
```

Pipeline triển khai có thể gọi CLI sau khi tạo URL revision riêng. Chỉ khi CLI thành công
mới được chuyển traffic theo BR-013; phần tích hợp này chờ US-029.

## 14. Test Scenarios

| Loại | Mô tả | Dữ liệu |
|---|---|---|
| Happy path | Ba route trả response hợp lệ và SHA khớp | Local HTTP stub; file tạm |
