## 1. Mục tiêu

- **Vấn đề cần giải quyết:**
  File [`requirements.txt`](file:///d:/file/project/Sign-Language-Classification-v1.0/requirements.txt) hiện đang sử dụng `opencv-python==4.11.0.86` và `opencv-contrib-python==4.11.0.86` (các bản desktop/GUI). Trên các image Linux tối giản (như `python:3.12-slim`), các thư viện đồ họa hệ thống (X11, Qt, OpenGL, GTK) không có sẵn. Nếu cài bản desktop, bước khởi động ứng dụng hoặc `import cv2` trong container Linux sẽ sập ngay với lỗi `ImportError: libGL.so.1: cannot open shared object file` hoặc `libgthread-2.0.so.0`.
- **Kết quả mong đợi sau US này:**
  1. File `requirements.txt` được chuẩn hoá sang dùng `opencv-python-headless==4.11.0.86`, loại bỏ hoàn toàn các gói desktop GUI.
  2. Toàn bộ file `requirements.txt` duy trì **100% thuần ASCII (Pure ASCII)** để tránh lỗi `UnicodeDecodeError` khi `pip` đọc trên Windows (mặc định bảng mã cp1252) cũng như Linux container.
  3. Giữ nguyên toàn bộ tổ hợp phiên bản đã kiểm chứng theo **`BR-005`** (`Python 3.12`, `tensorflow==2.19.1`, `keras==3.15.1`, `mediapipe==0.10.21`, `numpy==1.26.4 < 2`).
  4. Tạo bộ kiểm thử tự động [`tests/test_requirements.py`](file:///d:/file/project/Sign-Language-Classification-v1.0/tests/test_requirements.py) để canh giữ tính toàn vẹn của file phụ thuộc.
- **Phạm vi:**
  - Sửa đổi file `requirements.txt`.
  - Tạo bộ test tự động `tests/test_requirements.py`.
  - Cập nhật tài liệu quy trình và bộ nhớ dự án.
- **Ngoài phạm vi:**
  - Không nâng cấp các thư viện lõi (`mediapipe`, `numpy`, `tensorflow`) vì vi phạm BR-005.
  - Chưa viết file `Dockerfile` hoặc cấu hình CI GitHub Actions (thuộc Epic EPC-02, EPC-03).

## 6. Proposed Changes to `requirements.txt`

### 6.1. Hợp đồng phụ thuộc của `requirements.txt`

Đoạn cấu hình OpenCV được điều chỉnh như sau:

```text
# Truoc khi sua (Desktop GUI):
# opencv-python==4.11.0.86
# opencv-contrib-python==4.11.0.86

# Sau khi sua (Linux container headless):
opencv-python-headless==4.11.0.86
```

### 6.2. Quy tắc bắt buộc (Constraints)

1. **Pure ASCII:** 100% các ký tự trong `requirements.txt` phải có mã ASCII $\le 127$.
2. **BR-005 Compliance:**
   - `mediapipe==0.10.21` (bắt buộc nhánh `0.10.x` vì `1.0.0` đã xóa `mp.solutions`).
   - `numpy==1.26.4` (bắt buộc `< 2.0.0` do `mediapipe 0.10.x` yêu cầu).
   - `tensorflow==2.19.1` (tương thích Python 3.12).
   - `opencv-python-headless==4.11.0.86` (không dùng bản desktop).

## 7. Business Flow

```
CI Pipeline / Docker Build (Sprint 2)
  │
  ├──► FROM python:3.12-slim
  ├──► COPY requirements.txt .
  ├──► RUN pip install --no-cache-dir -r requirements.txt
  │      └── Tải opencv-python-headless (không đòi hỏi libGL.so.1 hay X11)
  │
  └──► Khởi động Backend API (Inference Service)

```

## 8. Security

| Mục | Giá trị |
|---|---|
| Dependency Pinning | Mọi phụ thuộc đều được ghim phiên bản cụ thể (`==x.y.z`), ngăn ngừa rủi ro chuỗi cung ứng (supply chain attack) do tự động tải phiên bản mới chưa qua kiểm thử |
| Gói thừa | Loại bỏ `opencv-contrib-python` giúp giảm diện tích bề mặt tấn công và dung lượng image |
