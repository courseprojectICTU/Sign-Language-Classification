## 1. Mục tiêu

- Vấn đề cần giải quyết: cấu hình Terraform hiện có trên nhánh dùng Google provider và GCS backend, không phù hợp hạ tầng Microsoft Azure đang vận hành.
- Kết quả mong đợi: Terraform dùng `azurerm`, lưu state trong Azure Blob Storage có cơ chế khóa, và nhận cấu hình staging/production riêng qua tfvars.
- Phạm vi: cấu hình provider/backend, bootstrap Storage Account và container cần thiết, tài liệu lệnh, kiểm thử cấu hình. Ngoài phạm vi: tạo hoặc thay đổi ACR, Container Apps, IAM triển khai và GitHub OIDC; các tài nguyên này thuộc User Story khác.

## 3. Existing Architecture

- Backend hiện có: FastAPI trên Azure Container Apps; cung cấp `/health`, `/predict` và `/version`.
- Frontend hiện có: chưa có trong repository; frontend dự kiến lưu trữ riêng.
- Module liên quan: nhánh hiện tại có bộ khung `infra/` nhưng đang khai báo Google provider, GCS backend và bootstrap bucket GCS.
- Cách chạy hiện tại: Terraform được chạy thủ công từ PowerShell; chưa có workflow CI/CD để triển khai hạ tầng.
- Quy ước response/error hiện có: không áp dụng cho cấu hình Terraform; lệnh Terraform trả exit code và diagnostic theo Terraform CLI.

## 6. Proposed API Changes

### 6.1. Hợp đồng CLI Terraform

- **Method:** N/A — lệnh dòng lệnh
- **Endpoint:** N/A
- **Purpose:** Khởi tạo backend từ xa và xem thay đổi dự kiến cho từng môi trường.
- **Authentication:** Azure CLI login tại môi trường chạy (`az login`) hoặc danh tính Azure được cấp quyền; không dùng credential tĩnh trong repository.
- **Authorization:** Bootstrap cần quyền tạo tài nguyên trong Resource Group; identity phải được admin cấp sẵn `Storage Blob Data Contributor` ở Resource Group hoặc Storage Account. US-018 không tự tạo role assignment.
- **Path Parameters:** Không áp dụng.
- **Query Parameters:** Không áp dụng.
- **Request Body:** Không áp dụng. Đầu vào là backend config và tệp `environments/<environment>.tfvars`.
- **Response:** Diagnostic Terraform CLI; mã thoát `0` khi init/plan thành công, khác `0` khi lỗi.
- **HTTP Status:** Không áp dụng.
- **Validation:** Terraform version đáp ứng constraint; tên Storage Account hợp lệ và duy nhất; tên container/key hợp lệ; môi trường thuộc `staging` hoặc `production`; tfvars trỏ tới đúng Azure subscription/Resource Group.
- **Business Rules:** `BR-014`; Azure Blob backend phải cung cấp khóa state để tránh apply đồng thời.
- **Error Cases:** Terraform báo lỗi khi thiếu quyền, sai backend config, Storage Account/container chưa tồn tại, hoặc tfvars không hợp lệ. Không được thay lỗi bằng giá trị mặc định thành công.

Lệnh dự kiến sau khi bootstrap Storage Account/container bằng Terraform:

```powershell
terraform -chdir=infra init `
  -backend-config="resource_group_name=<state-resource-group>" `
  -backend-config="storage_account_name=<state-storage-account>" `
  -backend-config="container_name=<state-container>" `
  -backend-config="key=sign-language-classification/staging.tfstate" `
  -backend-config="use_azuread_auth=true" `
  -backend-config="use_cli=true"
terraform -chdir=infra plan -var-file="environments/staging.tfvars"
```

Production dùng key `sign-language-classification/production.tfstate` và
`environments/production.tfvars`. Không chạy `apply` khi chưa có phê duyệt rõ
ràng của chủ dự án.

## 7. Business Flow

```text
Xác nhận Resource Group Azure đã tồn tại
  → đăng nhập Azure bằng danh tính được cấp quyền
  → terraform init/plan trong cấu hình bootstrap (local state riêng)
  → chỉ apply bootstrap sau khi chủ dự án duyệt
  → terraform init root module với Azure Blob backend và state key theo môi trường
  → terraform plan với tfvars tương ứng
  → Azure Blob lease khóa state khi Terraform thao tác
```

## 15. Risks

| Rủi ro | Ảnh hưởng | Giảm thiểu |
|---|---|---|
| Tên Storage Account Azure phải duy nhất toàn cục | Bootstrap có thể không tạo được tài nguyên | Nhận tên qua biến đầu vào; không hard-code giá trị chưa xác minh |
| Production Resource Group/subscription chưa có trong hồ sơ staging | Không thể chạy plan production chính xác | Không suy đoán; để giá trị production là cấu hình cần chủ dự án cung cấp trước khi plan |
| State GCP/local trước đây có thể còn trên máy hoặc backend cũ | Ghi đè hoặc vô tình quản lý state không thuộc Azure | Không tái sử dụng, migrate, ghi đè hay commit state cũ; dùng bootstrap Azure với local state path riêng |
| Thiếu Azure role hoặc Blob container chưa tồn tại | Init/plan thất bại | Bootstrap theo Terraform, cấp quyền tối thiểu và báo lỗi đầy đủ |
