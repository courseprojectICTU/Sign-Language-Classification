## 1. Mục tiêu

- **Vấn đề cần giải quyết:**
  Toàn bộ pipeline nhận diện ngôn ngữ ký hiệu tiếng Việt dựa trên một hợp đồng dữ liệu ngầm định: vector toạ độ landmark bắt buộc phải có đúng **93 phần tử** theo thứ tự giải phẫu học cố định:
  - 63 giá trị của bàn tay (21 điểm × `x, y, z` xen kẽ) đứng trước.
  - 30 giá trị của khuôn mặt (10 điểm mốc theo thứ tự `[10, 152, 234, 454, 33, 263, 1, 61, 291, 199]` × `x, y, z` xen kẽ) đứng sau.
  
  Mô hình ResNet50 được huấn luyện trên ma trận heatmap sinh ra từ vector 93 toạ độ này. Nếu một lập trình viên vô tình tráo đổi thứ tự hai điểm khuôn mặt, đảo chiều thứ tự tay/mặt, hoặc thay đổi danh sách `face_keypoints`, mô hình sẽ nhận dữ liệu sai toạ độ nhưng mã Python và Keras vẫn chạy bình thường mà **hoàn toàn không báo lỗi (silent failure)**. Đây là bẫy nguy hiểm nhất trong toàn bộ hệ thống ([BR-001](file:///d:/Sign-Language-Classification/docs/product-backlog-cicd-2-tuan.xlsx)).
- **Kết quả mong đợi sau US này:**
  1. Chuẩn hoá hằng số hợp đồng dữ liệu tại module `src/vsl/landmarks.py` làm nguồn chân lý duy nhất (Single Source of Truth) cho:
     - `FACE_KEYPOINTS`: bộ tuple bất biến `(10, 152, 234, 454, 33, 263, 1, 61, 291, 199)`.
     - `TOTAL_LANDMARK_COORDS`: 93.
     - `HAND_COORDS_COUNT`: 63 (21 landmark × 3).
     - `FACE_COORDS_COUNT`: 30 (10 keypoints × 3).
     - `LANDMARK_COLUMN_NAMES`: tuple 93 tên cột chuẩn (`hand_x_0, hand_y_0, hand_z_0, ..., face_z_199`).
     - Hàm kiểm tra hợp đồng: `validate_landmark_columns(columns)`.
  2. Re-export các hằng số này qua `src/vsl/__init__.py` và đồng bộ vào `src/vsl/service.py`.
  3. Xây dựng bộ test cưỡng chế hợp đồng tự động tại `tests/test_landmark_contract.py`:
     - Kiểm tra trực tiếp trên các file CSV thật trong `data/anphabet/`.
     - Kiểm tra trường hợp Negative Path: phát hiện lỗi ngay lập tức và chỉ rõ tên cột/vị trí bị lệch khi có bất kỳ sự thay đổi thứ tự nào.
- **Phạm vi:**
  - Module `src/vsl/landmarks.py`, re-export qua `src/vsl/__init__.py`.
  - Cập nhật import trong `src/vsl/service.py`.
  - File kiểm thử `tests/test_landmark_contract.py` bảo đảm `AC-015-01`, `AC-015-02`, `TSK-024`, `TSK-025`, `BR-001`.
- **Ngoài phạm vi:**
  - Không sửa đổi nội dung 1.609 file CSV thô trong `data/anphabet/`.
  - Không thay đổi kiến trúc mô hình ResNet50 hay hàm sinh heatmap `create_heatmap`.
  - Không tạo thêm endpoint HTTP mới.

## 6. Proposed API Changes

### 6.1. Hợp đồng Module Python `src/vsl/landmarks.py`

- **Loại:** Module hằng số và hàm tiện ích kiểm tra dữ liệu thuần Python (in-process).
- **Hằng số công khai (Public Constants):**
  - `FACE_KEYPOINTS: Tuple[int, ...] = (10, 152, 234, 454, 33, 263, 1, 61, 291, 199)`
    * 10 điểm mốc MediaPipe FaceMesh chuẩn hóa.
  - `NUM_HAND_LANDMARKS: int = 21` (Số điểm mốc bàn tay MediaPipe).
  - `NUM_FACE_KEYPOINTS: int = 10` (Số điểm mốc khuôn mặt trích xuất).
  - `HAND_COORDS_COUNT: int = 63` (21 × 3 toạ độ x, y, z).
  - `FACE_COORDS_COUNT: int = 30` (10 × 3 toạ độ x, y, z).
  - `TOTAL_LANDMARK_COORDS: int = 93` (63 + 30 = 93 toạ độ).
  - `LANDMARK_COLUMN_NAMES: Tuple[str, ...]`
    * Dựng sẵn tuple 93 chuỗi tên cột theo chuẩn:
      - 63 cột đầu: `hand_x_0, hand_y_0, hand_z_0, ..., hand_x_20, hand_y_20, hand_z_20`
      - 30 cột sau: `face_x_{idx}, face_y_{idx}, face_z_{idx}` với `{idx}` lần lượt lấy từ `FACE_KEYPOINTS`.
- **Hàm công khai (Public Functions):**
  ```python
  def build_expected_landmark_columns() -> Tuple[str, ...]:
      """Dựng danh sách chuẩn 93 tên cột landmark theo BR-001."""
      ...

  def validate_landmark_columns(columns: Sequence[str]) -> Tuple[bool, Optional[str]]:
      """Kiểm tra một danh sách tên cột có tuân thủ đúng hợp đồng 93 cột BR-001 hay không.
      
      Trả về:
          (True, None) nếu hoàn toàn hợp lệ.
          (False, reason_message) nếu vi phạm số lượng cột hoặc sai lệch thứ tự,
          chỉ rõ vị trí index và tên cột bị sai lệch đầu tiên.
      """
      ...
  ```

## 7. Business Flow

```
1. Module landmarks.py định nghĩa:
   FACE_KEYPOINTS = (10, 152, 234, 454, 33, 263, 1, 61, 291, 199)
   LANDMARK_COLUMN_NAMES = tuple 93 tên cột

2. Pipeline thu thập / trích xuất:
   Ảnh webcam -> MediaPipe Hands (21 điểm x,y,z = 63) 
              -> MediaPipe FaceMesh (10 điểm x,y,z = 30)
              -> Vector 93 toạ độ (Hand trước, Face sau)

3. CI Test Suite (tests/test_landmark_contract.py):
   -> Đọc file CSV thực tế trong data/anphabet/
   -> So khớp danh sách cột với LANDMARK_COLUMN_NAMES
   -> Xác nhận đúng 93 cột, đúng thứ tự hand trước face sau (AC-015-01)
   -> Giả lập sai lệch thứ tự (đổi chỗ điểm mặt, tráo tay/mặt)
   -> Xác nhận test phát hiện lỗi chính xác vị trí bị lệch (AC-015-02)
   -> Chặn pull request nếu vi phạm hợp đồng (BR-001)
```
