> **Trạng thái:** `ANALYSIS_READY` (đã nghiệm thu staging trên Azure Portal: `vsl-monthly-cost-guardrail-staging` và Entra ID `Security defaults: Enabled`)
> **Epic:** `EPC-09` · **Nhánh:** `feature/US-033` · **Ngày:** `2026-11-11`
> **Người soạn:** AI assistant · **Người duyệt:** Chủ dự án (chờ nghiệm thu Azure Portal)

> Đây là hợp đồng cho cấu hình Terraform Azure Billing Budget và quy trình kiểm soát

## 1. Mục tiêu

- Vấn đề cần giải quyết: nhánh `feature/US-033` trước đây khai báo `google_billing_budget`
  và tài liệu Google Cloud, lệch với hạ tầng **Microsoft Azure** đang chạy trên `develop`
  (`Azure for Students`, Container Apps `vsl-api`, App Service `vsl-vietnam`, ACR
  `vslacr3795`, remote state `vslstate2026`).
- Kết quả mong đợi: khai báo Azure Consumption Budget qua Terraform `azurerm` (`$5 USD/tháng`,
  cảnh báo ở `20%` = `$1` và `100%` = `$5`), hợp nhất hướng dẫn kiểm soát chi phí, dịch vụ
  bị cấm/được phép có điều kiện và kiểm tra MFA Microsoft Entra ID vào `docs/RUNBOOK.md`,
  kèm bộ kiểm thử tự động cho `US-033`.
- Phạm vi: `infra/budget.tf`, `infra/variables.tf`, `infra/outputs.tf`, `infra/README.md`,
  `docs/RUNBOOK.md`, tài liệu chỉ mục/quy trình và `tests/test_us033_cost_guardrails.py`.
- Ngoài phạm vi: tự ý `terraform apply` thay đổi tài nguyên live khi chưa có phê duyệt của
  chủ dự án, hoặc bật tắt thủ công MFA trên tài khoản Microsoft Entra ID từ môi trường local.

## 6. Proposed Changes (Terraform & Runbook Contract)

### 6.1. Terraform Azure Consumption Budget (`infra/budget.tf`)

- **Resource:** `azurerm_consumption_budget_subscription.monthly` (`count = var.enable_billing_budget ? 1 : 0`)
- **Scope:** `/subscriptions/${var.subscription_id}`
- **Tên ngân sách:** `vsl-monthly-cost-guardrail-${var.environment}`
- **Hạn mức & chu kỳ:** `amount = 5`, `time_grain = "Monthly"`
- **Khoảng thời gian:** `time_period.start_date = var.budget_start_date` (mặc định đầu tháng hiện hành định dạng RFC 3339 UTC `YYYY-MM-01T00:00:00Z`), kèm `lifecycle { ignore_changes = [time_period] }` để tránh drift khi sang tháng mới.
- **Hai ngưỡng cảnh báo (`Actual`):**
  1. `threshold = 20` (`$1 USD`), `operator = "GreaterThanOrEqualTo"`, `enabled = true`
  2. `threshold = 100` (`$5 USD`), `operator = "GreaterThanOrEqualTo"`, `enabled = true`
- **Người nhận thông báo:** `contact_roles = ["Owner"]` kết hợp `contact_emails = length(var.budget_alert_emails) > 0 ? var.budget_alert_emails : null` (không hard-code email cá nhân vào Git).
- **Biến bổ sung (`infra/variables.tf`):**
  - `enable_billing_budget` (`bool`, `default = true`): cho phép tắt nếu gói Azure for Students/Sponsorship chặn API `Microsoft.Consumption/budgets` tại môi trường cụ thể.
  - `budget_start_date` (`string`, `default = "2026-11-01T00:00:00Z"`, kiểm tra regex `YYYY-MM-01T00:00:00Z`).
  - `budget_alert_emails` (`list(string)`, `default = []`, kiểm tra định dạng email từng phần tử).
- **Output (`infra/outputs.tf`):** `billing_budget_id`.

### 6.2. Operations Runbook (`docs/RUNBOOK.md` — Mục 7)

Hợp nhất 4 nội dung vận hành chi phí vào Mục 7 của `docs/RUNBOOK.md`:
1. Cấu hình và kiểm tra Azure Cost Management Budget (`$1` / `$5`) + cổng Sponsorship (`https://www.microsoftazuresponsorships.com`).
2. Quy trình bật/kiểm tra MFA trên Microsoft Entra ID (Security Defaults / Conditional Access / tài khoản khách ngoài tenant; tách biệt với OIDC CI/CD không dùng mật khẩu tĩnh theo `US-019`).
3. Bảng dịch vụ/cấu hình Azure bị cấm và được phép có điều kiện theo `BR-016` (lưu ý `minReplicas = 1` trên staging hiện tại chỉ là ngoại lệ tạm thời có phê duyệt của chủ dự án).
4. Quy trình ứng phó khi nhận cảnh báo `$1` (20%) và xử lý sự cố ở `$5` (100%).

## 7. Business Flow

```
Chủ dự án / DevOps chạy Terraform với tài khoản Azure đã đăng nhập
  → đăng ký Microsoft.Consumption (nếu cần) và bật MFA trên Entra ID
  → terraform -chdir=infra plan/apply tạo azurerm_consumption_budget_subscription ($5/tháng)
  → (hoặc cấu hình/kiểm tra trên Azure Portal / Microsoft Azure Sponsorships nếu offer giới hạn API)
  → nếu chi tiêu chạm $1 (20%) → gửi email tới Owner + budget_alert_emails
  → đội vận hành thực hiện checklist Mục 7 trong docs/RUNBOOK.md để cô lập nguồn phí trước khi chạm $5
```

## 15. Risks

| Rủi ro | Ảnh hưởng | Giảm thiểu |
|---|---|---|
| Gói Azure for Students / Sponsorship chặn `Microsoft.Consumption/budgets` qua ARM/Terraform | Lệnh `terraform apply` có thể lỗi offer restriction ở bước tạo budget | Cung cấp `enable_billing_budget` toggle và ghi rõ quy trình cấu hình/kiểm tra tương đương trên Azure Portal / `microsoftazuresponsorships.com` trong `docs/RUNBOOK.md` |
| Đặt `start_date` ở tháng đã qua khi tạo budget mới | Azure API từ chối tạo budget mới | Cho phép truyền `budget_start_date` qua biến và gắn `lifecycle { ignore_changes = [time_period] }` |
| Thiếu quyền Entra ID Global/Authentication Admin để tự kiểm tra MFA trong phiên agent | Không thể tự xác nhận trạng thái MFA của các thành viên khác | Tài liệu hóa quy trình kiểm tra rõ ràng để chủ dự án xác nhận và chụp bằng chứng ở bước nghiệm thu |
