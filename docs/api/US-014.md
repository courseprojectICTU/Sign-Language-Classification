## 6. Proposed API Changes

### Chữ ký hàm Python: `src/vsl/heatmap.py:create_heatmap`

```python
def create_heatmap(
    landmarks: Union[Sequence[float], np.ndarray],
    img_size: Tuple[int, int] = (224, 224),
    sigma: Union[int, float] = 5,
) -> np.ndarray:
```

* **Quy tắc xác thực (Validation Rules):**
  1. `ndim == 1`: Vector đầu vào bắt buộc là mảng một chiều. Nếu là mảng 2 chiều hoặc đa chiều $\to$ ném `ValueError("Landmarks must be a one-dimensional numeric vector.")`.
  2. `size % 3 == 0`: Số lượng phần tử phải chia hết cho 3 (bộ 3 toạ độ x, y, z). Nếu không $\to$ ném `ValueError(f"Landmark data length {landmark_array.size} must be a multiple of 3.")`.
  3. `np.issubdtype(dtype, np.number)` và không phải số phức $\to$ ném `ValueError("Landmarks must contain real numeric coordinates.")`.
  4. `np.all(np.isfinite(...))`: Toạ độ không được chứa `NaN`, `+Inf`, `-Inf` $\to$ ném `ValueError("Landmarks must contain only finite coordinates.")`.
* **Trường hợp vector rỗng (`size == 0`):**
  * Hợp lệ theo định dạng (0 chia hết cho 3), hàm trả về ma trận toàn số 0 kích thước `(224, 224, 3)` kiểu `uint8` mà không gây lỗi chia cho 0 (`ZeroDivisionError`).
* **Giá trị trả về:**
  * Mảng `np.ndarray`, `dtype=np.uint8`, shape `(img_size[0], img_size[1], 3)`.

## 7. Business Flow

```
Input: landmarks (Sequence[float] | np.ndarray)
  │
  ├── 1. Ép kiểu sang np.ndarray (bắt TypeError/ValueError)
  ├── 2. Kiểm tra ndim == 1 (ném ValueError nếu sai)
  ├── 3. Kiểm tra size % 3 == 0 (ném ValueError nếu sai)
  ├── 4. Kiểm tra kiểu số thực (ném ValueError nếu chứa string/complex)
  ├── 5. Kiểm tra tính hữu hạn np.isfinite (ném ValueError nếu có NaN/Inf)
  │
  ├── 6. Khởi tạo heatmap = zeros(img_size, float32)
  ├── 7. Duyệt từng bộ toạ độ (x, y) nhảy bước 3:
  │      └── Nếu x == 0 and y == 0: bỏ qua (điểm khuyết)
  │      └── Nếu toạ độ nằm trong khung: cộng dồn nhân Gaussian (bán kính 3*sigma)
  │
  ├── 8. Chuẩn hoá chia cho max (nếu max > 0)
  ├── 9. Nhân 255 và ép kiểu uint8
  └── 10. np.stack 3 kênh giống hệt nhau -> Output (224, 224, 3)
```
