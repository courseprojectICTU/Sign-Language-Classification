## 6. Proposed API Changes

### 6.1. CLI `benchmark_cold_start.py`

- **Command:** `python scripts/benchmark_cold_start.py --url <staging-url> --preflight-command <command> --output <json-path>`
- **Purpose:** Chạy đúng 5 lượt độc lập; trước mỗi lượt chạy preflight command.
- **Inputs:** URL HTTPS; preflight command; output JSON; timeout tùy chọn.
- **Preflight output:** Một JSON object mỗi lần chạy, thuộc một trong hai dạng:

```json
{"mode":"scale_to_zero","active_instances":0,"min_instances":0,"revision":"revision-name"}
```

hoặc:

```json
{"mode":"fresh_revision","confirmed":true,"revision":"unique-revision-name"}
```

- **Validation:** Script dừng trước HTTP request nếu command lỗi, JSON sai, instance count khác 0, hoặc xác nhận revision mới thiếu.
- **Measurement:** TTFB tính từ lúc bắt đầu request đến byte đầu tiên của response body; total latency tính đến khi đọc hết body; chỉ chấp nhận HTTP 2xx.
- **Output:** JSON gồm timestamp, gate evidence, status code, TTFB/total latency của từng lượt và median/mean/min/max.
- **Error behavior:** Preflight hoặc request không thành công làm script thoát khác 0; không xuất báo cáo thành công giả.

## 7. Business Flow

```text
Lặp đúng 5 lần:
  -> chạy preflight command với COLD_START_RUN=<1..5>
  -> xác nhận scale-to-zero hoặc unique fresh revision
  -> gửi một HTTP request đến URL staging
  -> ghi status, TTFB, total latency và bằng chứng cold-state
Sau 5 lượt thành công:
  -> tính median/mean/min/max
  -> xuất JSON; người chạy cập nhật báo cáo markdown
```
