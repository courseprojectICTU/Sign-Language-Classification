  - Không sửa logic xử lý backend (`src/vsl/`), model machine learning, frontend tĩnh (`web/`), hay mã nguồn Terraform (`infra/`).

## 3. Existing Architecture

- **Backend hiện có:** Gói `src/vsl/` chuẩn hóa, dịch vụ FastAPI `src/vsl/service.py` hỗ trợ `GET /health`, `POST /predict`, `GET /version`, CORS đa nguồn qua `VSL_ALLOWED_ORIGINS`.
- **Frontend hiện có:** Giao diện web tĩnh `web/` gồm `index.html`, `app.js`, `styles.css`, `config.js`, `labels.json`, triển khai trên Cloudflare Pages (`https://sign-language-classification.pages.dev` và preview `https://develop.sign-language-classification.pages.dev`).
- **Hạ tầng hiện có:** Azure Container Apps Standard (`cae-vsl-staging-std` / `vsl-api`), Azure Container Registry (`vslacr3795`), Azure Blob remote backend Terraform (`vslstate2026`), quản lý chi phí qua `infra/budget.tf`.
- **Bộ nhớ dự án hiện có:** `AGENTS.md` (359 dòng, cập nhật lần cuối `2026-11-11`, baseline commit `dc9f9cd`).

### Hợp đồng thay đổi tài liệu (`AGENTS.md`):

1. **Header & Ngày cập nhật:** Đổi thành `2026-11-21` (hoặc thời điểm thực hiện phiên làm việc).
2. **Mục 2 (Git — trạng thái thực tế):**
   - Cập nhật baseline commit `develop` lên `8d3f15e` (hoặc commit merge mới nhất).
   - Bổ sung thông tin Release Production `v1.0.0` (commit `bf6c257`, tag `v1.0.0` trên `main`).
   - Bổ sung các PR đã merge: `US-032` (PR #57 / #58), PR #56 (CORS preview).
3. **Mục 3 (Cấu trúc thư mục):**
   - Bổ sung: `tests/test_us032_frontend_rollback.py`, `docs/api/US-032.md`, `docs/reports/US-032-BAO-CAO-THUC-HIEN.md`, `tests/test_us036_agents_contract.py`, `docs/api/US-036.md`.
4. **Mục 5 (Các bẫy đã xác nhận):** Bổ sung các bẫy thực tế:
   - **Bẫy 11 (Azure Entra ID OIDC Subject Claim):** Claim subject của token GitHub Actions chứa `@org_id` và `@repo_id` (`repo:courseprojectICTU@343123217/Sign-Language-Classification@1421059989:ref:refs/heads/...`). Cần chọn kịch bản `Other` thay vì `GitHub Actions` mặc định khi tạo Federated Credential trên Azure Portal để tránh lỗi `AADSTS700213`.
   - **Bẫy 12 (Windows Sandbox Python 3.12 DLL Failure):** Môi trường sandbox Windows chặn nạp `_ctypes.pyd` trong `.venv` (mã lỗi `0xC0000142`), khiến các công cụ CLI như `black` và `ruff` trong `.venv` bị lỗi. Giải pháp chuẩn là dùng Python 3.14 cài ngoài sandbox: `& "py" -3.14 -m black ...` và `& "py" -3.14 -m ruff ...`.
   - **Bẫy 13 (CORS Allowlist đa môi trường):** Cloudflare Pages tự sinh domain preview theo nhánh (ví dụ: `https://develop.sign-language-classification.pages.dev`). Biến môi trường `VSL_ALLOWED_ORIGINS` trên Azure Container Apps bắt buộc phải liệt kê cả domain production lẫn domain staging/preview để tránh lỗi CORS preflight 400.
5. **Mục 8 (Môi trường thực thi chuẩn):** Bổ sung hướng dẫn kiểm thử và format code với Python 3.14.
6. **Mục 10 (Tiến độ User Stories):** Bổ sung dòng `US-032` ở trạng thái `MERGED INTO DEVELOP (PR #57, #58)`.
7. **Mục 11 (Hướng dẫn tiếp tục công việc):** Chuyển trọng tâm sang `US-037` (Demo E2E & Retrospective), `US-030` (Cổng phê duyệt production) và `US-034` (Cảnh báo 5xx Log Analytics).
