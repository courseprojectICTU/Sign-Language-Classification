## 1. Mục tiêu

- **Vấn đề cần giải quyết:** Runtime hiện tại nạp trực tiếp mô hình H5 bằng TensorFlow/Keras (`train/vsl_cnn_pose_keras.h5`), làm tăng dung lượng container và thời gian khởi động. Backlog kỳ vọng khảo sát chuyển mô hình sang ONNX qua `SavedModel` và `tf2onnx` kèm parity test chặt chẽ.
- **Kết quả mong đợi sau US này:**
  - Cung cấp exporter tái lập (`scripts/export_onnx.py`) thực hiện H5 → `SavedModel` tạm → `model.onnx` và kiểm chứng nạp được bằng `onnxruntime` (`TSK-017`).
  - Cung cấp bộ kiểm thử parity (`tests/test_onnx_parity.py`) so sánh trực tiếp đầu ra Keras và ONNX Runtime (`CPUExecutionProvider`) trên cùng batch `23` heatmap sau tiền xử lý `BR-006`, kiểm chứng `max_abs_diff < 1e-4` và `argmax` trùng khớp `23/23` (`AC-011-01`, `TSK-018`), đồng thời đo dung lượng file và thời gian nạp/suy luận thực tế.
  - Nếu chuyển đổi hoặc parity thất bại (bao gồm xung đột toolchain `Keras 3.15.1` / `tf2onnx` / `protobuf 4.25.9`), kích hoạt đúng lộ trình dự phòng `AC-011-02`: ghi ADR `docs/decisions/US-011-onnx-fallback.md`, giữ nguyên runtime TensorFlow và bảo đảm pipeline + Docker build CI vẫn xanh.
- **Phạm vi:** `docs/api/US-011.md`, `scripts/export_onnx.py`, `tests/test_onnx_parity.py`, cấu hình dependency dev (`requirements-dev.txt`, thuần ASCII) hoặc ADR fallback (`docs/decisions/US-011-onnx-fallback.md`), `.gitignore` (bỏ qua artifact `.onnx` sinh cục bộ), tài liệu chỉ mục/trạng thái (`WORKFLOW.md`, `US-IMPLEMENTATION-STATUS.md`, `AGENTS.md`).
- **Ngoài phạm vi (chốt `Q1`–`Q2`):** Không sửa `src/vsl/service.py`, `Dockerfile`, `requirements-runtime.txt` hoặc chuyển runtime staging sang `onnxruntime` trong `US-011`; không sửa model weights H5, `create_heatmap`, thứ tự 23 nhãn hay `BR-006` preprocessing; không commit file nhị phân `.onnx` lên Git; không tự sửa code trước khi duyệt Cổng B và viết test Cổng C.

## 3. Existing Architecture

Kiểm chứng trực tiếp trên nhánh `feature/US-011` (đã đồng bộ `develop` `b54cbf7`, ngày `2026-11-11`):

- **Contract đầu vào/đầu ra:** Batch `(N, 224, 224, 3)` `float32` sau `preprocess_heatmap` (`keras.applications.resnet50.preprocess_input` kiểu Caffe), output `(N, 23)` xác suất softmax theo thứ tự `VIETNAMESE_ALPHABET` (`src/vsl/labels.py`).

  - `src/vsl/landmarks.py`: `TOTAL_LANDMARK_COORDS` (`93`).
  - `src/vsl/service.py`: `preprocess_heatmap(heatmap_batch)`.
- **Dữ liệu chuẩn 23 mẫu:** `data/anphabet/<letter>/1.csv` cho đủ 23 ký tự trong `VIETNAMESE_ALPHABET`.
- **Dependencies hiện tại:** `requirements.txt` & `requirements-runtime.txt` ghim `tensorflow==2.19.1`, `keras==3.15.1`, `mediapipe==0.10.21`, `numpy==1.26.4`, `protobuf==4.25.9`. ## 6. Proposed Changes (CLI, Module & Parity Contract)

### 6.1. Public HTTP API

- **Method / Endpoint:** `N/A` — US-011 không tạo hoặc sửa HTTP endpoint.

### 6.2. Exporter CLI & Python API (`scripts/export_onnx.py`, `TSK-017`)

- **Hàm chính:**
  - `export_keras_to_onnx(model_path: Path, output_path: Path, *, saved_model_dir: Path | None = None, opset: int = 15, overwrite: bool = False) -> dict[str, Any]`
  - `verify_onnx_session(onnx_path: Path, *, providers: list[str] | None = None) -> dict[str, Any]` (mặc định `["CPUExecutionProvider"]`, xác nhận ONNX Runtime nạp session thành công và trả tên/shape tensor input/output)
  - `compute_file_sha256(path: Path) -> str`
- **Tham số CLI (`python scripts/export_onnx.py`):**
  - `--model-path`: đường dẫn model H5 nguồn (mặc định `get_model_path()`, hỗ trợ `VSL_MODEL_PATH`, tuân thủ `BR-004`).
  - `--output`: đường dẫn file `.onnx` đích (mặc định `<PROJECT_ROOT>/models/model.onnx`).
  - `--saved-model-dir`: tùy chọn thư mục SavedModel; mặc định dùng `tempfile.TemporaryDirectory()` và tự dọn sau khi convert.
  - `--opset`: phiên bản ONNX opset nguyên dương (mặc định `15`).
  - `--overwrite`: cờ cho phép ghi đè nếu `--output` đã tồn tại (mặc định `False`; nếu file đã có mà không truyền `--overwrite` phải raise `OnnxExportError` / thoát mã lỗi `1`).
  - `--json-report`: tùy chọn ghi báo cáo JSON chứa metadata (`source_path`, `source_sha256`, `output_path`, `h5_size_bytes`, `onnx_size_bytes`, `opset`, `versions`, `input_names`, `output_names`, `input_shape`, `output_shape`, `saved_model_export_ms`, `onnx_convert_ms`, `ort_load_ms`).
- **Xử lý lỗi (`OnnxExportError`):**
  - Nếu thiếu file H5, `opset <= 0`, `--output` đã tồn tại khi `overwrite=False`, thiếu gói `tf2onnx`/`onnx`/`onnxruntime`, hoặc bước `SavedModel` / `tf2onnx` thất bại → raise `OnnxExportError` với thông báo rõ ràng, không tạo hoặc giữ lại file `.onnx` hỏng/dở dang (dọn temp/output partial), không sửa H5 nguồn.

### 6.3. Parity Helper & Benchmark Contract (`TSK-018`)

- **Chuẩn bị batch 23 mẫu:**
  - Đọc tuần tự 23 file `get_data_dir() / letter / "1.csv"` theo `VIETNAMESE_ALPHABET` (`BR-003`).
  - Kiểm tra đúng `93` tọa độ (`TOTAL_LANDMARK_COORDS`, `BR-001`), dựng heatmap qua `create_heatmap` (`BR-002`) ở dạng `uint8` `(224, 224, 3)`, stack thành `(23, 224, 224, 3)` và áp đúng một lần `preprocess_heatmap` (`BR-006`, kiểu Caffe BGR mean subtraction, **không** chia `255`) thành mảng `float32` dùng chung cho cả Keras và ONNX Runtime.
- **Đánh giá tương đương (`AC-011-01`):**
  - Chạy Keras inference trên `(23, 224, 224, 3)` (`training=False`).
  - Chạy `onnxruntime.InferenceSession` với `providers=["CPUExecutionProvider"]` trên cùng mảng `float32`.
  - Xác nhận cùng shape `(23, 23)` và kiểm tra:
    - `max_abs_diff = float(np.max(np.abs(keras_preds - onnx_preds))) < 1e-4`
    - `np.array_equal(np.argmax(keras_preds, axis=1), np.argmax(onnx_preds, axis=1))`
- **Đo thời gian (`Q4`):**
  - Tách riêng thời gian nạp model (`keras_load_ms`, `ort_load_ms`) và thời gian chạy inference sau 1 lượt warm-up (`keras_infer_ms`, `onnx_infer_ms`). Ghi chú rõ đây là số đo cục bộ/CI trên CPU, không phải container cold start.

## 7. Business Flow

```text
Đọc 23 CSV chuẩn (data/anphabet/<chữ>/1.csv theo VIETNAMESE_ALPHABET)
  → kiểm tra đủ 93 tọa độ (BR-001) → create_heatmap uint8 (224, 224, 3) (BR-002)
  → stack (23, 224, 224, 3) → preprocess_heatmap kiểu Caffe float32 (BR-006)
  → [Nhánh Keras] load H5 → suy luận lấy keras_preds (23, 23)
  → [Nhánh ONNX] export_keras_to_onnx (H5 → SavedModel tạm → tf2onnx → .onnx)
                 → onnxruntime (CPUExecutionProvider) → onnx_preds (23, 23)
  → Đối chiếu max_abs_diff < 1e-4 và argmax trùng 23/23 (AC-011-01)
      ├─ PASS: ghi nhận max_abs_diff, argmax 23/23, size H5/ONNX và timing load/infer
      └─ FAIL (thiếu/xung đột package, export lỗi hoặc diff >= 1e-4):
             tạo docs/decisions/US-011-onnx-fallback.md (AC-011-02), giữ nguyên TensorFlow
             và xác minh baseline 23/23 + Docker build CI vẫn xanh
```
