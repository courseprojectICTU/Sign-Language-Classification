Phân phối frontend tĩnh qua Cloudflare Pages/HTTPS, không phụ thuộc backend khi render trang, và kết nối trình duyệt tới FastAPI trên Azure. Không thay đổi UI hoặc chức năng của US-022.

## 3. Existing Architecture

- Frontend tĩnh: `web/index.html`, `web/styles.css`, `web/config.js`, `web/app.js`, `web/labels.json`.
- API: Azure Container Apps tại `https://vsl-api.wittyground-02475ae2.eastasia.azurecontainerapps.io`.
- Backend source tại HEAD có CORS middleware strict allowlist theo US-025 (`VSL_ALLOWED_ORIGINS`); production revision hiện hoạt động chưa có biến này và không trả CORS headers.
- Frontend initial render không gọi API; `labels.json` và các asset được tải từ cùng origin.

| API endpoint | `/health`, `/predict` đã tồn tại | REUSE |

## 6. Proposed API Changes

Không thêm endpoint. Backend cần allowlist origin chính xác `https://sign-language-classification.pages.dev`; cho phép GET/POST và preflight cần thiết; không dùng wildcard, không bật credentials. Cấu hình đề xuất theo nhánh US-025 có sẵn: `VSL_ALLOWED_ORIGINS=https://sign-language-classification.pages.dev`. Chưa triển khai biến này lên Azure trong phiên nghiệm thu.

## 7. Business Flow

```text
Browser → Cloudflare Pages HTTPS → HTML/CSS/JS/labels.json tải cùng origin
Browser → Azure /health hoặc /predict
Azure → CORS allow-origin chính xác → browser được đọc response
```

Hiện bước CORS bị thiếu ở Azure; static page vẫn render nhưng browser không đọc được API response.

## 8. Security

- Không đưa Cloudflare/API credential vào frontend.
- Production CORS chỉ cho origin Pages production; localhost và preview origin không được phép mặc định.
- Git Integration không cần Cloudflare API token trong frontend.
- CORS không phải cơ chế authentication/authorization.

## 15. Risks and Remediation

| Rủi ro | Nguyên nhân | Khắc phục |
|---|---|---|
| Browser không gọi được API | Revision production không có `VSL_ALLOWED_ORIGINS` và không phát CORS headers | Phê duyệt source US-025; đặt đúng origin Pages; phát hành revision mới; xác minh GET, POST, preflight và denied origin |
| Không xác định được chính xác source đang chạy | `/version` báo `git_sha: unknown`; image dùng tag `latest` | Build/release sau này cần gắn Git SHA hoặc immutable image digest; xác minh metadata trước khi traffic |
| Cold-start threshold chưa xác nhận | ACA hiện `minReplicas=1`, `maxReplicas=2`; backend không thể về 0 replica theo cấu hình hiện tại | Không đổi cấu hình production khi chưa được duyệt; đo trên staging hoặc kế hoạch thử scale-to-zero được phê duyệt |

## 17. Implementation Handoff

- **Cloudflare deployment:** chủ dự án xác nhận triển khai Pages thành công; project `sign-language-classification`; repository `courseprojectICTU/Sign-Language-Classification`; production branch `develop`; framework None; build command trống; output `web`; URL `https://sign-language-classification.pages.dev`; HTTPS assets đã được kiểm tra 200. Auto-deploy/branch controls chưa kiểm tra dashboard.
- **Azure production:** hostname thuộc Container App `vsl-api` / `rg-vsl-staging`, region East Asia; revision `vsl-api--latest` active/Healthy, 100% traffic, một replica, image `vslacr4751.azurecr.io/vsl-api:latest`. Đây là kiểm tra read-only; không truy vấn/hiển thị secrets.
- **CORS remediation:** source middleware và tests US-025 hiện có tại HEAD; production revision chưa được cập nhật. Một lần thử đăng ký Azure provider `Microsoft.ManagedIdentity` bị từ chối vì thiếu quyền subscription; kiểm tra sau đó xác nhận provider chưa đăng ký và không có image/app/identity staging nào được tạo. Azure đang ở `Single` revision mode nên không có candidate revision zero-traffic để smoke test độc lập. Sau khi subscription admin xử lý quyền và có phê duyệt riêng, thử trên Container App/staging riêng với `VSL_ALLOWED_ORIGINS=https://sign-language-classification.pages.dev`; chỉ cập nhật production bằng release workflow đã review, kèm rollback plan.
- **Smoke test sau khi CORS được triển khai:** (1) GET `/health` trực tiếp và với Origin Pages: 200, `model_loaded=true`, allow-origin exact; (2) OPTIONS `/predict` với Origin + `Access-Control-Request-Method: POST` + `Access-Control-Request-Headers: content-type`: 200/204, CORS headers đúng; (3) origin preview/khác không nhận allow-origin; (4) browser trên Pages gửi ảnh mẫu hợp lệ, xác nhận prediction và lỗi backend được hiển thị đúng; (5) GET `/version` xác nhận SHA/image release.
- **Đo AC-024-02:** chỉ trên staging hoặc sau phê duyệt thay đổi scale; xác nhận không còn replica trước mỗi lần chạy, mở Pages trong browser profile sạch/cache disabled, đo FCP bằng Performance API và xác nhận nội dung trước API interaction dưới 1000 ms. Ghi rõ trạng thái replica và từng số đo; không suy ra ngủ chỉ từ FCP.
