> **Business Rules:** BR-018 (CORS origin tường minh), BR-020 (Cloudflare token quyền tối thiểu, chỉ áp dụng nếu dùng API token)

## 3. Existing Architecture

- Frontend tĩnh: `web/index.html`, `web/styles.css`, `web/config.js`, `web/app.js`, `web/labels.json`.
- API: Azure App Service tại `https://vsl-vietnam.azurewebsites.net` (endpoint hiện được cấu hình trong `web/config.js`).
- Backend source có CORS middleware strict allowlist theo US-025 (`VSL_ALLOWED_ORIGINS`); App Service có setting origin production nhưng image hiện tại chưa có middleware và không trả CORS headers.
- Frontend initial render không gọi API; `labels.json` và các asset được tải từ cùng origin.

## 6. Proposed API Changes

Không thêm endpoint. Backend cần allowlist origin chính xác `https://sign-language-classification.pages.dev`; cho phép GET/POST và preflight cần thiết; không dùng wildcard, không bật credentials. Cấu hình đề xuất theo nhánh US-025 có sẵn: `VSL_ALLOWED_ORIGINS=https://sign-language-classification.pages.dev`. Chưa triển khai biến này lên Azure trong phiên nghiệm thu.

## 7. Business Flow

```text
Browser → Cloudflare Pages HTTPS → HTML/CSS/JS/labels.json tải cùng origin
Browser → Azure /health hoặc /predict
Azure → CORS allow-origin chính xác → browser được đọc response
```

Hiện bước CORS bị thiếu ở Azure; static page vẫn render nhưng browser không đọc được API response.

## 15. Risks and Remediation

| Rủi ro | Nguyên nhân | Khắc phục |
|---|---|---|
| Browser không gọi được API | Revision production không có `VSL_ALLOWED_ORIGINS` và không phát CORS headers | Phê duyệt source US-025; đặt đúng origin Pages; phát hành revision mới; xác minh GET, POST, preflight và denied origin |

| Cold-start threshold chưa xác nhận | ACA hiện `minReplicas=1`, `maxReplicas=2`; backend không thể về 0 replica theo cấu hình hiện tại | Không đổi cấu hình production khi chưa được duyệt; đo trên staging hoặc kế hoạch thử scale-to-zero được phê duyệt |

## 19. Chuẩn bị và chạy workflow publish image qua GitHub OIDC

Workflow [`acr-publish.yml`](../../.github/workflows/acr-publish.yml) chỉ build/push image lên `vslacr3795.azurecr.io/vsl-api`; không cập nhật App Service. Workflow dùng tag là Git SHA đầy đủ, build `linux/amd64`, kiểm tra `.h5` đã được Git LFS materialize, xác minh `GIT_SHA` trong image và so sánh digest từ Buildx với digest trong ACR. Chưa có build/push nào chạy.

### GitHub Actions Variables

Trong repository **Settings → Secrets and variables → Actions → Variables**, tạo:

| Variable | Giá trị |
|---|---|
| `AZURE_CLIENT_ID` | Application (client) ID của Entra app registration dùng riêng cho workflow |
| `AZURE_TENANT_ID` | Directory (tenant) ID |
| `AZURE_SUBSCRIPTION_ID` | Subscription chứa ACR |

OIDC không cần ACR admin username/password hoặc client secret; không tạo hay dùng các credential đó cho workflow này.

### Microsoft Entra federated credential

Trong app registration tương ứng, thêm Federated credential với:

| Field | Giá trị |
|---|---|
| Issuer | `https://token.actions.githubusercontent.com` |
| Audience | `api://AzureADTokenExchange` |
| Subject | `repo:courseprojectICTU/Sign-Language-Classification:ref:refs/heads/bugfix/US-024-cors` |

Subject giới hạn token cho đúng repository và nhánh fix; không dùng wildcard subject.

### Quyền ACR tối thiểu

Gán role `AcrPush` cho service principal của app registration **trên riêng resource ACR `vslacr3795`** (không gán ở subscription/resource group và không dùng ACR admin account). Nếu service principal chưa được tạo, Azure admin cần tạo nó từ app registration trước. Lấy resource IDs khi cấu hình bằng Azure CLI:

```powershell
$ClientId = "<AZURE_CLIENT_ID>"
$AcrId = az acr show --name vslacr3795 --query id -o tsv
$PrincipalObjectId = az ad sp show --id $ClientId --query id -o tsv
az role assignment create `
  --assignee-object-id $PrincipalObjectId `
  --assignee-principal-type ServicePrincipal `
  --role AcrPush `
  --scope $AcrId
```

Tài khoản quản trị thực hiện lệnh cần quyền tạo role assignment tại scope ACR (ví dụ Role Based Access Control Administrator hoặc Owner). Không lưu giá trị nhạy cảm trong repository hoặc chat.
